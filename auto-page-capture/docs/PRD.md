# Auto Page Capture - 产品需求文档（PRD）

## 1. 背景与目标
用户希望在 Chrome 浏览器中对当前打开的网页进行“自动化留存”：
- 自动滚动获取全页截图（按屏保存）
- 可选自动翻页继续截图（分页站点）
- 支持手动停止
- 自动导出文本（优先导出 DOM 文本）
- 所有产物保存到本地 Downloads 目录

## 2. 目标用户
- 需要归档网页资料的学生/研究人员/工程师
- 需要保存长文、教程、分页文章的用户

## 3. 范围（V1）
### 3.1 必须（Must）
1) 一键开始任务（当前 Tab）
2) 自动滚动截图（每屏一张 PNG）
3) 保存到本地（Downloads/page_capture/...）
4) 一键停止任务（1 秒内生效）
5) 导出网页文本（DOM 提取，保存 page.md）
6) 进度显示（正在截图、已保存、错误信息）

### 3.2 可选（Should）
1) 自动翻页：识别 “下一页/Next/rel=next” 并点击继续任务
2) 导出长截图 PDF（优先单页，过长自动回退多页）

### 3.3 暂不做（Won’t in V1）
- 长图拼接（整页合成 1 张）
- OCR（从截图识别文字）
- 云端同步/上传

## 4. 用户流程
1) 用户打开目标网页
2) 点击扩展图标 → popup
3) 选择模式（滚动/翻页）、延迟等参数
4) 点击 Start
5) 扩展开始截图并保存，同时在 popup 显示状态
6) 用户可随时点击 Stop
7) 完成后生成截图、page.md、long_capture.pdf（按开关配置）
